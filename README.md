# Breast Cancer Classification Using Stacking

## Project Overview

This project develops a machine learning system for **breast cancer classification** using a **stacking ensemble learning approach**.

The goal is to classify breast tumors as **Benign** or **Malignant** based on numerical features extracted from breast cell measurements.

Instead of relying on a single machine learning model, multiple base models are combined using a **stacking architecture**.

## Dataset

The project uses the **Breast Cancer Wisconsin (Diagnostic) Dataset**.

The dataset contains:

* **569 samples**
* **30 numerical features**
* A `diagnosis` target variable
* `B` — Benign
* `M` — Malignant

The diagnosis labels were encoded as:


B → 0
M → 1


The `id` column was removed because it is only an identifier and does not provide useful predictive information.

## Data Preprocessing

The following preprocessing steps were performed:

* Loaded the dataset
* Checked the dataset structure
* Checked missing values
* Checked duplicate records
* Removed the id column
* Encoded the target variable
* Separated features and target
* Performed a stratified train/test split
* Standardized numerical features using `StandardScaler

The data was divided into **80% training and 20% testing data**.

## Stacking Architecture

The stacking model consists of two levels.

### Level-0 Base Models

Three different machine learning models were used as base learners:

* Logistic Regression
* Perceptron
* Decision Tree

Each model produces predictions from the input features.

### Level-1 Meta Model

The predictions generated by the Level-0 models are combined and provided to a **Logistic Regression meta-model**.

The meta-model learns how to combine the predictions of the base models to produce the final classification.


                  Input Features
                        │
          ┌─────────────┼─────────────┐
          ↓             ↓             ↓
   Logistic Regression Perceptron Decision Tree
          │             │             │
          └─────────────┼─────────────┘
                        ↓
                 OOF Predictions
                        ↓
               Logistic Regression
                 Meta-Model
                        ↓
              Final Classification
                 Benign / Malignant


## Out-of-Fold Predictions

To train the meta-model without introducing information leakage, **out-of-fold (OOF) predictions** were generated using cross-validation.

Each training sample receives a prediction from a model that was trained without that sample.

These OOF predictions are then used as input features for the Level-1 meta-model.

## Model Evaluation

The models were evaluated using:

* **F1 Score**
* **ROC-AUC**
* Confusion Matrix
* Classification Report
* ROC Curve

The performance of the individual base models was also compared with the final stacking model.
